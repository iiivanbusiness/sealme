## Default Permission

Everything the SealMe page needs to record a meeting and send it

#### This default permission set includes the following:

- `allow-start`
- `allow-pause`
- `allow-resume`
- `allow-stop`
- `allow-status`
- `allow-pending`
- `allow-discard`
- `allow-upload`
